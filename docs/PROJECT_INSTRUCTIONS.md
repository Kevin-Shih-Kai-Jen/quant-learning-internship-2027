【本專案所有聊天室必讀】
這些指示僅適用於「Quant Learning & Internship 2027」專案內的所有聊天室，作為每次開始或繼續任務時的持續規則；不得套用到其他專案。

本專案的歷史資料以私人 GitHub 儲存庫及其版本化 Releases 為主保存位置：
https://github.com/Kevin-Shih-Kai-Jen/quant-learning-internship-2027

1. 每次開始或繼續任務時，先閱讀 repo 的 AGENTS.md、research/project_archive_20260924/MEMORY_BRIEF.md 與 data/index.json，再依本次任務查 docs/EXPERIMENT_INDEX.md、相關報告與資料目錄。不要一次把整套歷史資料放進對話。
2. 若無法存取私人 repo，必須明說尚未讀取，保留未同步資料，繼續不依賴缺失內容的工作；不可假裝已讀到其他聊天室、已備份或已清理。
3. 需要大型實驗資料時，依 docs/DATA_GUIDE.md 從版本化 Release 按需下載到本次專屬臨時目錄，記錄 tag、取回清單與目錄，核對容量及 SHA-256。需要還原時在該臨時目錄進行，不長期保留大量資料在本機。
4. 將本次任務產生的新程式、筆記、報告、設定與必要實驗資料同步到上述私人 repo：小型可讀檔案進 Git，大型資料用新的版本化 Release。新成果另開版本，保留原始研究及修正／失敗紀錄，不改公開、不覆寫或刪除雲端歷史。
5. 用完後，先確認新成果已成功同步，並核對遠端 Git 內容、Release／catalog 大小與 SHA-256 及可取回狀態，再刪除本次專屬臨時目錄內可重新下載的本機副本、還原檔與操作暫存。使用者已授權這個範圍，無須每次重問；沒有新成果時，也要確認來源仍可取回。
6. 不刪未同步、校驗失敗、歸屬不明、其他工作正在使用的檔案；不刪其他專案或 sources/、research/sources/ 等同步唯讀材料。新成果優先放在常駐 repo 的新實驗目錄；同步失敗時保留並回報。
7. 本機長期保留輕量導讀、工具、索引及必要的未同步內容。完成後回報遠端位置、取回版本、核對範圍及實際清理範圍。這些授權不包含部署網站、向他人發訊息、任意清空專案或刪除雲端資料。
