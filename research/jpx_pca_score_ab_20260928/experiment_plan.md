# JPX PCA 分數消融 A/B：事前固定計畫（2026-09-28）

使用者授權用 B 診斷共同方向是否增加 JPX 分數。正式基準 v7_equal 保持；只轉換既有已保存預測，不重新訓練、不改官方排名配重。

## 比較
A：原 v7_equal 預測與排名，必須重現原 953 日未年化 Sharpe 0.007678871562421042。
B_PC6：每日以當時可得的股票報酬估計 PCA，移除當日第六主成分 loading 對預測分數的橫斷面線性成分（含截距回歸，但只扣 loading 項、保留分數平均）。
B_MAX：同一估計中，以 A 原權重被 PCA 涵蓋部分的 λ_k (w_A'v_k)^2 最大者為所選方向，做相同分數消融。這是被涵蓋持倉的最大估計方向，並不包含缺值股票的未知風險。選擇僅用當時報酬、原預測和原持倉，不用當日未來 Target。
兩個 B 同時預先指定，不事後挑勝者。B_MAX 是可操作的「當下最大估計風險方向」檢驗；B_PC6 是第六方向規則，均不能稱為追蹤 2021-12-01 的同一個科技因子。

## 時序與缺值
每日訊號收盤時計算，報酬窗口最多 252 個市場交易日，至少 120 個；初期不足 252 日使用所有已知有效市場日並明確記錄。2017 暖身後從原 953 個 validation 訊號日評估，未使用保留 test。
使用原當日排名股池；PCA 只納入回看窗口每日報酬皆有效且非恆定的股票。不截尾、不裁切、不填報酬缺值；個股任一端缺價或零成交量保留缺值，全市場休市不列為交易日。先算相鄰市场交易日報酬，再選欄，避免跨缺口報酬。
只減每檔時間平均、不按標準差縮放。使用樣本共變異數 T−1，全部非零方向供 B_MAX 選擇。PCA 未涵蓋的股票維持原預測，仍在完整排名股池中，不將未知 loading 宣稱為零風險；報告每天涵蓋股數、原持倉 gross 覆蓋率。
設 fit 股池 loading 為 v，q=v−mean(v)，s 為原分數，b=q'(s−mean(s))/(q'q)；新分數 s_B=s−bq。未涵蓋股票不變。固定消融強度 100%，不搜尋比例。
並列以證券代碼升冪打破同分；多空各 200 檔，各側極端名次 2→1。保留 original Target，不用價格報酬重建取代。

## 評估
兩階段：先用無 Target 的介面產生並保存全部 B 分數／排名／所選方向，再獨立讀 Target 評分。原始 A 評分須逐日重現保存數值。
比較相同可評分日期的官方未年化 Sharpe（主要）、每日 Spearman Rank IC 平均（次要）、年度結果、平均 spread、spread 標準差、選股變化、原方向曝險及總估計風險。任何入選缺 Target 的日期對 A/B 使用共同日期排除並列出，不補零。
報告配對 stationary block bootstrap 的 Sharpe 差異探索區間：平均區塊長度 20 日、5,000 次、固定 seed 20260928；不以區間或超參數搜尋選模型。年度 split 與既有 validation 相同，不能冒稱新的保留 OOS。
策略權重仍由 JPX 公式決定。未模擬實盤交易成本或複利；若報換手，僅為權重變化診斷，不是扣成本績效。
