# JPX：return／前 22 日平均 − 1，加 1 日價格 return

已依確認，將價格、成交量的 5／22／60 日 return 都套用新比值，另加入原始 1 日價格 return。953 個 validation 區間累積報酬 −52.77%，最大回撤 77.58%；上一版原 return 基準為 −6.56% 與 41.00%。本次試驗未改善績效，原研究基準保留。

## 特徵定義

對 X = 調整後價格或成交量，k = 5、22、60：

R_k(t) = X(t) / X(t−k) − 1

M_k(t) = [R_k(t−1) + … + R_k(t−22)] / 22

Q_k(t) = R_k(t) / M_k(t) − 1

另外加入 PR1(t) = P(t)/P(t−1) − 1，維持原始 1 日報酬。平均不含當日。原三個同期間交乘項改為 QPR5×QVR5、QPR22×QVR22、QPR60×QVR60；總計 10 個輸入加截距。沒有新增 1 日量特徵。

個股仍只用上一年訓練，每年重估；市場 regime 維持 T 值、expanding 市場訓練與既定中性邊界。配置、錯號轉移、成交與延後退出沿用原引擎。

## 分母與數值檢查

原式保留負平均、真實的非零小分母，沒有加 epsilon、取絕對值或截尾；完整視窗缺值、分母等於零時不進候選。

7638 在 2018-11-05 的前 22 筆 60 日價格 return，正負相互抵銷，數學平均精確為零。浮點 return 曾使它看起來像 −3.53×10^−17，造成約 10^15 的假比值。使用原始價格與拆股因子的精確分數核對後，依事先規則排除這筆。這是修正數值誤差，沒有把非零小分母任意排除。

排除精確零後，非零分母仍讓有效比值達到百萬級，這個特徵形式仍有不穩定性。下表為全資料的最大絕對比值，非僅訓練集：

| 原始 return | 最大絕對比值 |
|---|---:|
| PR5 | 718,281.25 |
| PR22 | 3,858,337.30 |
| PR60 | 2,449,236.55 |
| VR5 | 17,347,459.53 |
| VR22 | 5,747,742.77 |
| VR60 | 1,675,761.33 |

比值也會混合原本不同的方向資訊：+1%／+1%−1 與 −1%／−1%−1 都等於 0。這些是形式上的限制，但尚未做逐項歸因，不能宣稱某一項已證實造成虧損。

## 可比較性與驗證

本次同時變更六個價量輸入、三個交乘項並新增 PR1，不能把結果單獨歸因於 1 日 return。新增 22 日完整視窗後，最長特徵需至少 83 筆市場交易日觀測，候選集合自然縮小。

數值求解使用可逆的欄尺度轉換以維持精度，再將係數轉回原始輸入單位。沒有減去均值、除以標準差或加入正則化，預測公式仍直接使用使用者指定特徵。SVD 與 QR 兩種分解的訓練預測一致，所有年度矩陣保持滿秩。

獨立核對 4,898 個平均與比值計算，並核對交乘項、原 PR1、上一年訓練範圍、已知標籤時間、所有選股預測與市場預算。事件損益與每日報酬完成對帳；資料末端無未平倉。
