# 價量 return 除以前 22 日平均，加入 1 日價格 return

使用者已確認：價格與成交量都套用。對各 k = 5、22、60，先沿用原始 R_k(t) = X(t)/X(t-k)-1，再計算 Q_k(t) = R_k(t) / mean(R_k(t-22),...,R_k(t-1)) - 1。22 個市場交易日不含當日，不因個股缺值縮短視窗。另加入原始 1 日價格 return；原三個同期間價量交乘項改乘新的 Q。共 10 個輸入加截距。沒有新增 1 日成交量或 1 日交乘。

個股訓練維持退回的上一年資料，年度重訓，所有訓練標籤於首個 validation signal 當時已知。目標仍為原始 Target。市場 regime、股票當日基本資格、預算、錯號轉移、交易與延後退出規則沿用前版。

平均值由前 22 個完整有效 return 計算，使用較高精度加總降低抵銷誤差。分母精確為零、視窗缺值或產生非有限輸入則不進候選；非零分母不設定額外下限、不取絕對值、不截尾、不加 epsilon。負平均保留負號。市場全面休市沿用上一交易日特徵。

浮點平均絕對值小於 1e−12 時，只觸發原始價格、股數與拆股因子的精確分數重算，並非排除門檻。若數學上為零，依原規則視為不定義；真正的非零小數保留。

若輸入尺度導致原始矩陣求解不穩定，允許在數值求解內使用可逆的欄尺度轉換，再將係數轉回原始輸入單位。此步不改特徵定義，不減均值、不改預測公式，也不加正則化。以另一種分解及原始輸入預測核對。

比較相同 953 個 validation 區間的上一年訓練原 return 版。候選集合因新增完整視窗而可能改變，記錄此差異。這次同時變更比值特徵與新增 1 日價格 return，不能單獨歸因。無 test、零交易成本、無參數搜尋。本版是試驗，原研究基準保留。
