# JPX：價量 return 轉成 T 值

本次將原始價、量 return 放入前 22 日 T 值公式，並重新訓練、選股與回測。953 個相同 validation 區間累積報酬 +47.39%，年化報酬 +10.80%，最大回撤 36.09%。比前兩個 return 實驗改善，但回撤仍大於最早價格／量水準 T 值版及日經基準。

## 本次定義

價格：R^P_k(t) = 調整後 P(t)/調整後 P(t−k)−1，k = 1、5、22、60。

成交量：R^V_k(t) = 調整後 V(t)/調整後 V(t−k)−1，k = 5、22、60。

對上述每一種原始 return：

T_R(t) = [R(t)−mean(R(t−22),...,R(t−1))] / std(R(t−22),...,R(t−1))

平均、樣本標準差均使用前 22 個市場交易日，不含當日；標準差 ddof=1。沿用 T 值稱呼，這裡的公式是滾動 z-score。新增的 1 日價格 return 也經相同轉換。

三個交乘項為 TPR5×TVR5、TPR22×TVR22、TPR60×TVR60。模型共有十個輸入與截距，預測目標仍為原始個股 Target。沒有將 Target 轉成 T 值，也沒有先做 return／平均−1 再標準化。

## 保持的設定

個股只用上一年合格資料訓練，每年重新估計，所有標籤在首個 validation signal 當日已可觀察。Regime 保持市場 T 值、expanding 市場訓練、初始 ±0.1%、正負各 10% 歷史邊界及 0.6 當年原始邊界 + 0.4 去年原始邊界。

市場訊號、預算、前三名權重、錯號轉移、目標價成交與無交易日延後退出規則全部沿用。標準差為零或視窗缺值時不進候選；沒有補零、截尾或加 epsilon。市場全面休市沿用上一交易日特徵。

## 特徵穩定性與限制

價格 return 的 T 值最大絕對值約 72（包含 1 日 return）；成交量 return 的 T 值仍可超過 1,000。比上一個除以平均的百萬級比值小很多，但當日變化極端時仍會有大值，沒有做額外裁切。

以 return 減去平均再除以標準差，可以避免「平均正負互抵接近零」直接作為分母的問題。不過，這不能保證交易獲利。

最早的 T 值版直接對價格／量水準做 5／22／60 日標準化，且沒有 1 日價格特徵；本次對不同期間 return 統一使用前 22 日標準化。兩者不是只改了單一欄位，不能將差異全部歸因於 return 的 T 值。相較上一個比值版，本次也把 PR1 一併轉成 T 值。

候選集合因完整視窗與標準差有效性而改變，最長特徵需 83 筆市場交易日觀測。

## 驗證與輸出

獨立核對 5,716 個平均、樣本標準差與 T 值計算；檢查所有零標準差列均排除、交乘項正確、全面休市特徵延續、上一年訓練範圍與標籤截止日正確、全部選股預測可重算、市場日期與預算一致。事件損益與每日報酬對帳通過，資料末端無未平倉。

仍使用相同無正則化平方誤差目標；SVD 求解與 QR 分解交叉核對。數值求解的可逆欄尺度轉換已還原為實際 T 值輸入單位的係數。

相同 953 個 validation 區間、零交易成本、原理想化區間觸價成交假設；沒有使用 test 或搜尋參數。這些 validation 已用於多次模型開發，不是全新保留樣本。
