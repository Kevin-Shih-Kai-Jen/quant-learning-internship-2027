# 價量 return 轉為 22 日 T 值

依使用者要求，將原始價、量 return 放入 T 值公式。沿用上一個實驗前 22 個市場交易日、不含當日的視窗：T_R(t) = [R(t) − mean(R(t−22),...,R(t−1))] / sample_std(R(t−22),...,R(t−1))，標準差 ddof=1。

被轉換的原始 return 為 5／22／60 日價格、5／22／60 日成交量，以及新增的 1 日價格 return，共七項。同期間三個價量交乘改為 TPR5×TVR5、TPR22×TVR22、TPR60×TVR60。十個輸入加截距。這次直接標準化原始 return，不先計算 return／平均−1，也不同於最早直接標準化價格／成交量水準。

歷史視窗有缺值、標準差為零或輸入非有限時不進候選；不加 epsilon、不截尾、不補零。使用 long-double 計算完整視窗平均與樣本標準差，避免不必要的數值誤差。市場全面休市沿用上一交易日特徵。

个股維持上一年訓練、下一年 validation，年度重訓，所有訓練 Target 必須在首個 validation signal 當日已可觀察。目標仍為原始個股 Target。市場 regime 保持已驗證的市場 T 值、expanding 市場訓練與既定平滑邊界。交易、配置與錯號轉移不變。

比較原始 return 版、上一個除以平均的比值版、最早價格水準 T 值版。固定 953 個 validation 區間，無 test、零成本、無參數搜尋。記錄候選集合差異，核對公式、訓練時間、選股預測、資金配置與交易損益；各實驗資料保留。
