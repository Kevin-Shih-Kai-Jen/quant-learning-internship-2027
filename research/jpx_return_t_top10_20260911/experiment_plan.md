# Return T 模型：每側前十名，側內等權

依使用者要求，將目前 return T 值模型的各側前三名擴大為各側前十名，並將各側資金等權配置。市場 regime 的多／空初始預算仍為 70/30、50/50、30/70；因此每個初始槽位分別為 7%/3%、5%/5%、3%/7%。最多二十個不同股票的新選股槽位。

沿用原錯號轉移：原槽位預測方向不符，整個槽位的預算轉移到尚未使用的反方向股票；精確零則留現金。轉移保留来源側預算，因此轉移後同一實際方向的各股票不一定等權。側內等權指初始多方、空方預算各除以十。方向不符、零預測、資料不足、停牌、已持有股票等情況均不得以未来資料重新選股。

完全固定最新 jpx_return_t_20260911 的特徵、年度係數、候選與預測：七個原始 return 的前 22 日 T 值，加三個同期間交乘；個股上一年訓練；市場 T 值與 expanding 市場模型、平滑邊界不變。不重新訓練、不調參。

重算每日排名並先核對舊三名規則能重現所有舊選股、權重與預測，再用十名等權進入原始交易引擎。零交易日延後退出與占用資金、缺乏行情及已持有股票留現金等規則不變。新增持倉權重相對於當日可用資金分配，而非假設延後部位不存在。

固定 953 validation 區間、零交易成本、無 test。比較現行三名 50/30/20 與十名等權的總報酬、最大回撤、年化、Sharpe、年度結果及單筆損失。不得根據結果挑選名次或權重參數。
