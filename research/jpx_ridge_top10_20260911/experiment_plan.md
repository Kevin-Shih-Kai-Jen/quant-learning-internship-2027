# Return T ＋每側十名等權：加入 Ridge

依使用者要求，將個股損失改為 mean((Target − b − Xβ)^2) + λ sum(β_j^2)。只懲罰十個特徵係數，不懲罰截距。沿用現有 return T 特徵及交乘項的單位；不再額外標準化、不截尾、不更動 Target。若需數值尺度轉換，必須同步換算懲罰，不能誤罰另一個參數化的係數。

事前固定 λ 候選為 [0, 0.001, 0.01, 0.1, 1, 10, 100]，包含 λ=0 對照。每一個外層 validation 年仍只用上一年資料訓練。將該年合格訓練 signal 日期依時間排序，以 50%／75% 日期為界建立兩個內層驗證折：前 50% 訓練、下一個 25% 驗證；前 75% 訓練、最後 25% 驗證。每折訓練只保留 label ExitDate <= 該折首個驗證 SignalDate 的列。按日期分割，不把同一天股票拆到兩邊。

以兩折合計平方誤差／合計驗證列數選 λ，精確同分取較小 λ。選定後，在該外層年的完整上一年合格訓練集重新擬合。內層驗證資料及其標籤均來自當時已知的外層訓練資料。禁止使用外層 2018–2021 年度報酬或誤差選 λ；不在看完結果後擴大網格。網格邊界若勝出須報告，不能宣稱最佳值已被定位。

模型以中心化後的原始 T 特徵計算 Ridge 正規方程，截距恢復為 y_mean − x_mean·β。與增廣設計矩陣最小平方法交叉核對。檢查 λ=0 係數能重現目前模型，Ridge 係數 L2 範數不超過無懲罰版本。
