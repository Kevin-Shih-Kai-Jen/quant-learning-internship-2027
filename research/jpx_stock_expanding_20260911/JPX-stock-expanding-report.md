# JPX：個股 expanding window 訓練

已按要求將個股改成 expanding window。新版維持未標準化價量 return，2018–2021 的 953 個 validation 區間累積報酬為 −41.47%，最大回撤為 47.52%。前次只用上一年訓練的 return 版為 −6.56% 與 41.00%。

## 訓練方式

每年從 2017 年起累積合格股票資料，重新估計同一組全股票共用係數，年內固定。只使用當年首個 validation signal 時已觀察到完整標籤的資料；條件為 SignalDate < fit_asof 且 ExitDate <= fit_asof。歷史資料等權重，沒有時間衰減。

| Validation 年 | 累積資料年份 | 合格訓練列 | 訓練時間界線 | 最後訓練標籤退出日 |
|---|---|---:|---|---|
| 2018 | 2017 | 344,393 | 2017-12-29 | 2017-12-29 |
| 2019 | 2017–2018 | 806,860 | 2018-12-28 | 2018-12-28 |
| 2020 | 2017–2019 | 1,269,407 | 2019-12-30 | 2019-12-30 |
| 2021 | 2017–2020 | 1,744,723 | 2020-12-30 | 2020-12-30 |

訓練列數會超過舊年度訓練列數的直接加總，因為過往年末尚不可觀察的標籤，在後續年份已可加入。

## 維持的模型與交易設定

- 個股：PR_k = P_t/P_(t−k) − 1，VR_k = V_t/V_(t−k) − 1，k 為 5、22、60；價格與量沿用先前驗證的拆股調整。
- 九個輸入：三個價格 return、三個量變化率及三個同期間價量乘積；原 Target、不標準化、不截尾、無正則化。
- 沿用原始特徵上的共軛梯度法，求解相同平方誤差目標，並核對最小平方法的係數。
- Regime：市場 T 值、expanding 市場模型、初始 ±0.1% 與正負各 10% 邊界、0.6 當年原始邊界 + 0.4 去年原始邊界。重用相同的 953 筆市場訊號。
- 相同候選資格、配置、錯號轉移與交易引擎；使用新個股預測重新排序選股。

## 檢查與限制

已確認每年訓練集合包含前一年集合、所有訓練標籤於估計當時已知、validation 候選與市場日曆一致。2018 的係數、選股與每日報酬和前次 return 版一致；配置權重、事件損益與每日報酬完成對帳，資料末端沒有未平倉部位。

兩個 return 版本的差異只在個股訓練時間範圍。T 值版僅供參考，並非本次將 T 值模型也改為 expanding。

沿用零交易成本及原理想化觸價成交假設；2021 資料至 12 月 3 日，非完整全年。未使用 test；這些 validation 資料已參與多次開發比較，不是全新保留樣本。
