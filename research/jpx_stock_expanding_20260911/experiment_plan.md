# 個股模型改為 expanding window

使用者指定的唯一模型變更：個股每年訓練時，累積採用 2017 年開始、首個 validation signal 日期當時已完整觀察到 Target 的所有合格歷史資料。2018 使用 2017；2019 使用 2017–2018；2020 使用 2017–2019；2021 使用 2017–2020。實際截止由 Label ExitDate <= fit_asof 決定；每年重新估計全部係數，年內固定。

特徵維持已驗證的未標準化價格／成交量 5、22、60 日 return 與同期間交乘項；目標仍為原 Target，無截尾、無正則化、無新特徵。沿用原始特徵上共軛梯度求解同一平方誤差目標，與最小平方法核對。

市場 regime、門檻、股票候選資格、配置、錯號轉移及交易引擎保持上一版設定。直接重用已驗證的特徵及市场訊號，重新訓練、預測、排序選股與執行。對照為前次個股只用上一年訓練的 return 版；另列 T 值版與日經供參考。

核對：所有訓練標籤於訓練時間前已知、訓練集合逐年包含前一年集合、候選列及市場日曆不變、2018 訓練及回測與原 return 版一致、各日配置正確、事件損益對帳、資料末端無未平倉。953 validation 區間、無 test、零交易成本，沒有參數搜尋。
