# JPX：個股價量改用未標準化 return

已實作使用者指定變更。953 個相同 validation 區間中，新版累積報酬 −6.56%，最大回撤 41.00%；目前 T 值版為 +34.78% 與 23.06%。本次結果未改善整體表現。

## 輸入與模型

對 k = 5、22、60 個市場交易日：

- 價格 return：PR_k(t) = 調整後價格(t) / 調整後價格(t−k) − 1。
- 成交量變化率：VR_k(t) = 調整後成交量(t) / 調整後成交量(t−k) − 1。
- 九個輸入：PR5、PR22、PR60、VR5、VR22、VR60，以及 PR5×VR5、PR22×VR22、PR60×VR60。
- 模型：g = α + Σ β_k PR_k + Σ γ_k VR_k + Σ δ_k PR_k VR_k。目標仍為原始個股 Target。
- 使用小數：上升 5% 輸入 0.05；不減均值、不除標準差、不截尾、不做額外正則化。
- 價格除以 signal 日以前的累積調整因子；成交量乘以該因子。因子依原程式於下一交易日生效。
- 分母為零或端點缺值時不定義 return，當日不進候選。60 日 return 需要 61 筆觀測；市場全面休市沿用上一交易日特徵。

## 保持的設定

個股仍用上一年資料訓練、下一年 validation；全股票共同估計一組係數，沒有改成 expanding 個股訓練。標籤必須在首個 validation signal 當日已可觀察。市場 regime 維持 T 值與 expanding 訓練，直接重用已驗證的 953 筆市場訊號：初始 ±0.1%，正、負各取最靠近零的 10%（向上取整），再以 0.6 當年原始邊界 + 0.4 去年原始邊界計算。

多／中／空初始預算維持 70/30、50/50、30/70；各側前三名權重 50/30/20，錯號部位依原規則轉移。使用新預測重新選股。成交、目標價觸及、無交易日延後退出、保留占用資金等規則皆沿用原交易引擎。

區間為 2018–2021 的 953 個 validation 持有區間；2021 資料至 12 月 3 日，並非完整全年。最大回撤以跌幅正數顯示。

## 可比較性與求解檢查

原 T 值需視窗內有可計算的標準差；新 return 對平盤可以等於零，但需要 t−k 的有效分母。因此可用樣本自然改變，不能把績效差異全部歸因於相同候選集合上的特徵替換。未另加沿用舊 T 值資格的篩選。

四年舊模型訓練筆數、係數與全部 5,718 個原始選股槽位已重現。新輸入尺度差異使原始 GD 未通過既定收斂／精度檢查；改用原始特徵上的共軛梯度法，沒有預先縮放特徵，目標仍是相同無正則化平方誤差。共軛梯度解與直接最小平方法的係數最大差異均小於 1e−9。詳細迭代數、條件數、係數與訓練時間界線見 model_fits.json。

交易事件損益加總已與每日報酬核對；市場日期、基準報酬、預算權重與原設定一致。另由使用者原始 ZIP 的價格、成交量與逐段拆股因子獨立核對端點公式，檢查結果見 independent_audit.json。

## 資料範圍

只讀取使用者提供的 JPX_data.zip 與 JPX-market-regime-experiment.zip，未使用 test。沿用零交易成本、理想化區間觸價成交假設；validation 已用於多次開發比較，不是全新保留樣本。這是研究回測結果。

本次沒有參數搜尋，也沒有根據新版結果變更門檻、配置、輸入裁切或交易規則。原 T 值版與所有過往實驗另行保留。

主要檔案：results.json（績效）、model_fits.json（係數）、old_reproduction.json（舊版核對）、independent_audit.json（獨立檢查）、requested_orders.csv（下單前選股）、selected_trades.csv（成交與持倉）、daily_returns.csv（每日報酬）、position_events.csv（交易事件）、run_experiment.py（重現入口）。
