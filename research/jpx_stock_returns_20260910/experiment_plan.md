# 個股價量改用未標準化 return

固定變更：個股價格與成交量輸入改為 5、22、60 個市場交易日的簡單變化率 X[t]/X[t-k]-1。價格使用除以過去累積調整因子的價格；成交量使用乘以該因子的股數。同期間價量交乘保留，改乘新 return。無標準化、無截尾、無額外正則化。成交量是變化率，非投資報酬率。

沿用上一年訓練個股模型、下一年 validation；訓練 label 必須於首個 validation signal 當日已可觀察。目標維持原始 Target。沿用 market T 值、expanding market 訓練、初始 ±0.1%、各正負 10% 邊界及 0.6 當年原始邊界 + 0.4 去年原始邊界。直接重用已驗證的 regime 訊號，禁止重選參數。

沿用原配置、錯號轉移與交易引擎。先重建舊模型與選股確認，再用新模型重新選股。分母為零或端點缺值時不定義 return，當日不進候選；市場全面休市日沿用上一交易日特徵。60 日 return 需 61 筆觀測。個股停牌不縮短交易日索引。

輸入僅讀使用者指定兩個 ZIP。953 個 validation 區間，無 test、零交易成本。未標準化量變化率尺度可能使原始梯度下降無法於既定步數收斂；如遇到，改用原始設計矩陣上的共軛梯度法，保持同一無正則化平方誤差目標，並以最小平方法交叉驗證。不得為改善報酬調參。
