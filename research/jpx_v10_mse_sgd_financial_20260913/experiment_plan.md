# v10：v7 普通 MSE + 逐檔 SGD + v9 財報衰減

本計畫於擬合前固定。使用者要求：不要使用 soft rank，用 v7 的 loss function，加入現在 v9 的 SGD 與財報衰減。

- 主模型 `mse_sgd_financial`：11 個既有價量特徵、截距 α，加一個財報特徵 z，共 13 個係數。對照組 `mse_sgd_control` 的 z 固定為 0，其餘相同。
- 每日等權目標為 mean((g_i−Target_i)^2)。單筆 SGD loss=(g_i−Target_i)^2，梯度=2(g_i−Target_i)x_i，包括 α；β 梯度=2(g_i−Target_i)z_i。沒有 soft rank、真實排名 loss、RMSE、ridge 或額外財報交互項。排名只用於輸出與績效評分。
- 2017-01-04 係數全部初始化為零，Target 實現後，對該日可用標籤逐檔各更新一次；跨日跨年延續參數，不重訪舊日期。沿用 v9 每日亂序種子 20260912+YYYYMMDD。
- 沿用 v9 SGD 學習率試探：先 0.1，成功則 0.2…1.0，遇到首個未改善即停止；若 0.1 失敗，依序 0.09…0.01、0.009…0.001，直到 0.000009…0.000001，選第一個滿足條件者。每次從相同更新前參數與梯度試探，需嚴格降低該筆 loss 且滿足 Armijo c=1e−4。梯度無窮範數≤1e−10 跳過。全部候選失敗則記錄並跳過，不擴展學習率範圍。
- 候選 loss 用實際候選參數重新算報酬 MSE，沒有用 v7 每日整批的特徵值學習率。
- z 完整沿用已稽核的 v9 SignalDate 財報快取：r×(本期營業利益/營收−去年同期營業利益/營收)，第一個可用交易日 r=1，接續 0.9…0.1，第 11 個交易日歸零。公告時點、同期匹配、訂正、缺值與不截尾規則不變。成熟日更新仍使用預測當日的 z，不重新衰減。
- 使用相同核心股票池、SupervisionFlag 排除、資料缺值回補、2020-10-01 休市規則，以及 2018–2021 共 953 個驗證日。所有預測先產生後評分；缺 Target 不影響當日預測池。
- 主要比較財報版與無財報 SGD；v7 每日整批 MSE 與 v9 soft-rank SGD 僅引用已完成的歷史結果。官方風格固定多空各 200 檔、2→1 權重，報告未年化 Sharpe。
- 同時保存預測 MSE、每日更新前後 MSE、逐筆梯度摘要、參數歷史、排名與獨立稽核。結果不佳亦完整報告，不依驗證結果調整參數。未扣交易成本，沒有新的獨立 test。
