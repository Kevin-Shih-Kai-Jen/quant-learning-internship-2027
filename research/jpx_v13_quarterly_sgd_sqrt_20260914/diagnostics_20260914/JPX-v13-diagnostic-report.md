# v13 為什麼表現差：診斷與下一輪檢驗順序

本輪只分析既有預測及原始來源，未重訓，也未按驗證結果修改公式。已確認資料口徑錯配和近零分母造成特定極端預測；尚不能量化修正後的整體績效。應先修資料，再檢验模型假設。

## 1. 先修正已確認的資料錯配

1808（長谷工）2018-03-15 官方公告同時列出合併與個別預測。個別營收預測為 5800 億日圓、合併為 8200 億。原始檔取到個別值，v13 卻依「唯一已知歷史口徑」推定為合併，與前三季合併實際營收 5801.52 億相減，錯誤推出第四季預估 −1.52 億。[公司公告，第 1 頁](https://www.haseko.co.jp/hc/ir/news/upload_files/20180315_1.pdf)

下一財年第一季預估 2200 億，相對這個錯誤的 −1.52 億基準，形成 1448.37 倍季增。2018-05-14 混合組的預測報酬為 10.326（小數單位，即約 +1033%），其中營收預測季增貢獻 10.322。這一例可直接追溯到配對問題，而非使用者的剩餘季度公式本身。

先前的稽核驗證算式與時間順序，但未能驗證原始 ForecastRevision 的會計口徑。此為實作檢查的缺口。只有歷史狀態唯一，不能證明新修正屬於相同口徑。後續需要明確的公告或資料欄位證據；無法辨識者應標記缺失，不應猜測歸屬。其他錯配數量與 v12 是否受影響尚需全面回查。

## 2. 即使算式正確，近零分母仍會讓預測失真

4324 的一筆 EPS 事件：去年同季基準 −0.01，本季實際 4.64，事前季度預估 75.6567。因分母只取 0.01，實際成長率為 465 倍、預期成長率為 7566.67 倍。2019-08-09 單獨 SGD 的財報預測貢獻 −128.5596，主要由預期 EPS 成長部分的 −150.9472 和實際 EPS 成長的 +22.3744 組成。

| 同樣 953 日、按日等權的誤差診斷 | 單獨 SGD | SGD＋√N |
|---|---:|---:|
| 平均每日 MSE | 0.03820259 | 0.00159566 |
| 全部預測為零的 MSE | 0.00059222 | 0.00059222 |
| MSE／零預測 MSE | 64.51 倍 | 2.69 倍 |
| 前五檔股票占 MSE | 60.85% | 15.55% |
| 最大 100 個股票日占 MSE | 77.99% | 32.73% |
| 預測絕對值大於 100% 的股票日 | 1254 | 72 |

SGD→混合組的 MSE 淨改善，有 63.36% 集中於前五檔股票。因此「MSE 改善 95.8%」不能單獨當作預測訊號變強的證據。零預測只是一個數值誤差基準，所有股票分數相同，並沒有提供選股排名。

下一輪應先固定一個只利用訓練期資料的尺度／近零基期處理規則，另做對照。不能根據驗證期最差的股票名單把它們剔除；上表是事後定位錯誤來源，不是可交易篩選規則。

## 3. MSE 降低主要是預測幅度縮小，排序訊號仍接近零

平均每日橫截面 Rank IC（分數與實際報酬的排名相關）為：單獨 SGD −0.002239、混合組 −0.003963。兩者均接近零。952 日可計算；2020-09-29 全股票 Target 為零，該日 IC 未定義，保留在 953 日報酬／MSE 評估中。

按日分解：

MSE = 平均預測偏差² + 預測變異 + 實際報酬變異 − 2×預測與實際報酬共變異。

兩組 MSE 改善的 98.20% 對應預測橫截面變異的降低。平均每日預測標準差從 9.585% 降到 1.402%。這是數學分解，沒有證明哪個訓練機制有因果效果；它說明誤差變小主要不是因為多找到了正確的排序。

兩組每日預測排名相關平均 0.3266，多頭／空頭股票重疊約 30.86%／30.69%，所以追加更新也確實改變了選股。混合組空頭標的平均上漲更多，放空側是拖累的一部分。2018 年占組間淨多空收益減幅的 86.0%，2021 年則反而改善。

固定已擬合參數拆開看，價量部分 Rank IC 為 −0.001821／−0.003975，財報部分為 −0.002466／+0.001181。這不是重新訓練的純價量、純財報控制，不能當成因果歸因，但也不支持把失敗全部歸咎財報。

20 日區塊、5000 次配對 bootstrap，混合組減 SGD 的 Sharpe 差約 −0.02533，探索性 95% 區間為 [−0.10242, +0.05161]，包含零。此區間受資料問題、樣本重複使用、時間穩定性假設限制；不能斷言追加整體更新必然降低真實績效。

## 4. 季度 Forecast 變動含有實績扣除的機械效果

同財年、能配對上一季度事前預估的事件中，全年 Forecast 未改變的比率：營收 76.84%、營業利益 76.88%、EPS 63.63%。若 F 不變，由已知 k−1 季轉為已知 k 季，有：

Q_new − Q_old = (Q_old − R_k)/(4−k)。

所以本季實際 R_k 優於原先平均預估，剩餘季度的平均預估必然下降。這是分配規則的結果，不等於公司主動下修未來展望。實際驚喜與這項推算季增可能在表達相互關聯的資訊。

需要把「全年 Forecast 改變」與「全年不變、只是公布新實績」分組測試。不能把後者全部解讀為新的預期修正，也不能在未檢驗前認定它完全無用。

## 5. 折價參數目前不宜解讀成市場折價

953 個驗證日，相鄰驗證日 EPS 折價 d 改變超過 0.5：單獨 SGD 110 次、混合組 93 次。它與 β 相乘，對尺度和訓練路徑敏感。這是先固定 d=1 做簡單對照的理由，不是它導致負 Sharpe 的證明。

## 建議的檢验順序

| 順序 | 做法 | 要回答的問題 |
|---|---|---|
| 1 | 核實年度、季度、合併／個別、單位及修正歸屬；無證據就缺值 | 輸入是否具有一致的經濟意義？ |
| 2 | 對單一原始訊號，分事件後 1、5、10、20 交易日，做分組報酬與 Rank IC | 訊號在哪個可交易期間有排序資訊？ |
| 3 | 固定 d=1、同一訓練器，從價量基準逐項加入實際驚喜、Forecast 修正、推算季增、推算年增 | 哪一項有增量貢獻？是否只是重複訊息？ |
| 4 | 尺度規則只用訓練資料設定；比較有無穩健尺度處理，固定其他設定 | 結果是否由少數近零分母主導？ |
| 5 | 有了可靠特徵後，才比較 SGD、SGD＋√N、是否學 d | 是模型學不到已有訊號，還是原本訊號就弱？ |

目前 Target 對應 SignalDate 後下一日收盤到再下一日收盤的報酬；財報在收盤或之後公布，還需到下一可用收盤才進入特徵。因此事件研究應把公告即时反應與策略實際能交易的後續期間分開。這裡只是標籤與時間設定的檢查，尚未測得本資料的最佳影響期間。

所有實驗應固定時間切分、保存完整試驗紀錄，並預留未使用的新區間確認。多次在同一回測樣本上挑選設定會增加挑到歷史噪音的風險。[Bailey 等，The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)
