# V13 固定預測的排名與報酬診斷

僅讀取既有 v13 輸出及對應 Target；没有重訓、調參或改寫原始實驗。953 個驗證日、每組 1,864,363 筆排名。Rank IC 是全股票預測 g 與 Target 的 Spearman 相關，排除 Target 缺失值；2020-09-29 全股票 Target=0，該日相關未定義，因此平均 IC 有 952 個有效日。

|---|---:|---:|
| 平均每日 Rank IC | −0.002239 | −0.003963 |
| 平均每日 Pearson IC | −0.001579 | −0.003804 |
| 固定已擬合價量部分 Rank IC | −0.001821 | −0.003975 |
| 固定已擬合財報部分 Rank IC | −0.002466 | +0.001181 |
| 多頭側每日加權報酬 | +1.059 bps | +0.412 bps |
| 空頭標的每日加權原始報酬 | +2.011 bps | +3.200 bps |
| 多頭減空頭每日報酬 | −0.952 bps | −2.788 bps |
| 多頭相對全股票平均報酬 | −0.704 bps | −1.350 bps |

| 未年化 Sharpe | −0.01686 | −0.04218 |
| 平均每日預測橫截面標準差 | 9.585% | 1.402% |

空頭標的原始報酬為正，代表放空該側的報酬為負。表中的多頭減空頭是各側權重合計各為一的差額；若總曝險為一、多空各半，報酬再除以二。以上均未扣交易成本。

兩组的每日預測排名平均相關僅 0.3266；多頭 200 檔平均重疊 30.86%，空頭重疊 30.69%。因此新增總體更新明顯改變了選股排序，並非單純把所有分數等比例縮小。

利用等日權 MSE 恆等式

MSE = (平均預測 − 平均實際)² + Var(預測) + Var(實際) − 2 Cov(預測, 實際)

拆解，混合組 MSE 比單獨 SGD 降低 0.03660693，其中 **0.03594816，約 98.20%，來自預測橫截面變異減少**。這是代數分解，說明主要改善在預測幅度穩定；它不證明哪一項訓練機制造成變異縮小，也不代表已學到穩定的排序訊號。

價量部分是 g − FinancialContribution，使用原模型已擬合的固定參數；財報部分是已儲存的 FinancialContribution。兩者都沒有獨立重訓，所以不能當作正式的純價量控制或財報因果歸因。混合組的價量部分 IC 也接近零偏負，因此現有結果不支持把所有失敗歸咎財報特徵。

2018 貢獻混合組相對 SGD 全期平均多空報酬淨減幅的 86.0%；2021 反而改善。這不支持「混合組每年一定較差」的說法。

## 不確定性

以同一日期同步抽樣兩組，20 個交易日為一區塊，做 5,000 次 circular moving-block bootstrap（固定 seed 20260914）：

- Rank IC 差（混合−SGD）：−0.001724；95% 百分位區間 [−0.009082, +0.005054]。
- 平均每日多空報酬差：−1.836 bps；95% 區間 [−6.366, +2.749] bps。
- Sharpe 差：−0.02533；95% 區間 [−0.10242, +0.05161]。

這些區間皆包含零，因此只能說本次樣本的混合組排序表現較差，尚不能斷言其真實績效比 SGD 差。此為已反覆使用驗證樣本上的探索性不確定性評估，未涵蓋模型挑選偏誤或不同時期的結構改變。
