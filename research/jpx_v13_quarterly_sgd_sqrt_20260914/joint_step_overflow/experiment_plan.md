# v13: quarterly expectation events, SGD versus SGD + floor(sqrt(N)) daily updates

User approved formulas and comparison on 2026-09-14. This plan is fixed before fitting.

Both arms retain the existing 11 price/volume features, including PR1 and VR1 divided by their own trailing 22-session sample standard deviation, including signal day, without demeaning. Both use ordinary return MSE and identical chronological label maturity, stock pool, seed and evaluation as v12. No soft rank. The additional full-day steps use ONLY the newly matured day's known labels, equally weighted. N is the number of eligible finite-label stocks on that day. First perform N individual SGD updates, then the hybrid arm attempts floor(sqrt(N)) full-day gradient updates, recomputing gradients after each update. SGD-only attempts no full-day updates. No historical replay. Report attempted and accepted steps separately.

For each of NetSales, OperatingProfit and EPS: Q=(annual Forecast-current fiscal YTD actual)/(4-k), where k is the latest reported quarter. k=0 implies YTD=0. Only regular twelve-month fiscal years with matching normal quarterly boundaries are eligible; nonstandard/shortened years are excluded from financial features, not from the price stock pool. Full-year reports route their guidance to the next fiscal year. Nonannual ForecastRevision rows are conservatively excluded, as in v12. EPS uses the user-approved cumulative difference arithmetic; per-share changes from share-count changes mean this is an approximation, not reconstructed exact standalone EPS.

Financial events have five stored raw components per metric: actual YoY growth u, preannouncement implied-quarter forecast YoY growth v, forecast QoQ q, forecast YoY y, guidance revision urev. Actual event requires BOTH actual and prior forecast and last-year same-quarter actual. Actual score is beta_A*(u-d*v). Other scores are d*(beta_Q*q+beta_Y*y+beta_U*urev). Historical forecast comparison values are the last same-quarter forecasts strictly before that quarter's first actual publication; freeze these forever. Missing preannouncement guidance is not replaced by hindsight. Forecast QoQ/YoY are emitted once per target-quarter and metric when the estimated quarter first becomes available; unchanged restatements do not restart events. Revisions emit only when annual guidance changes, comparing old/new guidance using identical currently known YTD, k and prior-year actual baseline. On a quarter rollover, initial forecast growth and an identifiable annual guidance revision can coexist with separate coefficients.

Actual and revision baseline is last-year same-quarter actual. Growth is (x-base)/abs(base). No clipping, no arbitrary epsilon, no magnitude cap. Missing/nonfinite/zero baseline makes that individual event unavailable. Events are frozen at creation. Each decays exp(-age_in_trading_sessions/9), first usable market close age=0, never explicitly cut off. Old events sum with new events. Corrections update future known state only; they never regenerate a prior actual surprise or rewrite past frozen expectations. Corrections to annual guidance can generate a new revision event. Correction-only changes to YTD update future residual forecasts but do not masquerade as annual forecast revisions.

27 model parameters: 12 price/volume including intercept, 12 event coefficients, 3 metric-specific shared discounts. Initialize all linear coefficients to zero once, discounts to 1. Discounts learned jointly by projected SGD/GD on [0,1]. Forecast-only beta*d products are not separately interpretable without the actual-surprise linkage; report discount values as fitted model parameters, not observed market pricing.

Learning-rate candidates retain v12 grid: try .1 then .2 to 1 while each improves; if .1 fails try .09... .01 down to .000009... .000001, first accepted. Armijo c=1e-4 uses gradient dot the actual projected displacement; candidates evaluate the nonlinear model after clipping discounts. Strict loss reduction required. Gradient/projection stationarity skips are recorded. No tuning based on evaluation results.

Evaluate the same 953 validation sessions with 200 long and 200 short official-style weighted spreads, unannualized Sharpe and all-stock daily forecast MSE. Also report stage-specific training losses and discount trajectories. Preserve complete ranks, daily parameters, individual-step traces and independent replay verification. Prior models are descriptive references only. No transaction costs and no fresh untouched test set.
