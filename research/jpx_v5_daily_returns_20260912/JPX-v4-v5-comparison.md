# JPX v4 與 v5：加入一日價量變動率

2026-09-12。依本次命名，原價量水準 T 值模型為 **v4**；新增一日價格報酬率與成交量變動率的版本為 **v5**，並設為目前研究模型。v5 的歷史驗證 Sharpe 為 **0.04674**，v4 為 **0.01750**。

## 模型定義

- **v4**：原有 9 個特徵：T5、T22、T60、V5、V22、V60，以及同期間的三個價量 T 乘積。
- **v5**：上述 9 個特徵，加上 PR1 與 VR1，共 11 個特徵與截距；所有係數重新擬合，不是固定 v4 係數後額外加兩項。沒有新增 PR1×VR1。

以拆股等公司行動調整後的價格 P*、成交量 V* 計算：

`PR1[t] = P*[t] / P*[前一實際交易日] − 1`

`VR1[t] = V*[t] / V*[前一實際交易日] − 1`

例如價格由 100 變成 103，PR1=0.03；成交量由 1,000 變成 1,500，VR1=0.50。這兩個新特徵不標準化、不截尾。原有 T 特徵維持原定義。

**一日變動率其實可以標準化**：可用過去多日的變動率估計平均數、標準差；只有單一觀測值無法自行估計有意義的標準差。本次依要求直接使用原值。

調整方式沿用既有資料：CumulativeFactor 是截至前一列的 AdjustmentFactor 累積乘積，P*=Close/CumulativeFactor，V*=Volume×CumulativeFactor。全市場休市的 2020-10-01 不計入前一交易日；個股零量或缺價日不任意跳過。前值為零或不可用時，變動率標為缺失。

## 公平比較與評分

兩版均使用前一曆年訓練、每年重新擬合，訓練標籤的實現日期不晚於該折訓練截止日。四折訓練樣本數均相同：341,063、451,552、450,406、465,079；新特徵未使訓練樣本減少。目標函數維持無正則化線性 MSE。v4 以原梯度下降係數重現；v5 使用原始特徵的直接最小平方法，另以 QR 與最適條件殘差交叉核對；沒有因求解器改變而加入標準化或懲罰項。

兩版均無 regime、Ridge、softmax、訊號正負資金轉移或交易成本。每日按 g 由大到小給唯一 Rank，最高 200 檔做多、最低 200 檔做空，即使所有 g 同號也照樣選取兩側。每側從最極端排名起套用由 2 線性降至 1 的 200 個權重。

官方每日 spread 為兩側 Target 加權和之差，再除以權重平均值 1.5；官方 Sharpe = 每日 spread 平均 / 樣本標準差（ddof=1），**不乘 √252**。依據：[JPX 官方競賽評分程式](https://www.kaggle.com/code/smeitoma/jpx-competition-metric-definition)。

## 結果：JPX 未年化 Sharpe

| 驗證期間 | 天數 | v4 | v5 |
|---|---:|---:|---:|
| 2018 | 245 | -0.06209 | -0.03672 |
| 2019 | 241 | 0.11312 | 0.11854 |
| 2020 | 242 | 0.03242 | 0.07415 |
| 2021 | 225 | -0.03724 | 0.03640 |
| **全部合併** | **953** | **0.01750** | **0.04674** |

合併分數直接使用全部每日 spread 計算，不是四個年度 Sharpe 的平均。若僅供一般年化尺度參考，乘 √252 後 v4=0.27779、v5=0.74201；這兩個年化值不是競賽分數。

四個年度都改善，其中 2021 由負轉正，2018 仍為負。這支持在目前歷史驗證中保留這兩個新增特徵，但不代表已證明未來或正式 test 也會改善。

## 驗證範圍與限制

這是已多次用於模型開發的 2018–2021 年歷史驗證資料，並非新保留測試集、正式 test 或 Kaggle 排行榜成績。股票池與 v4 完全一致：使用提供的核心股票資料，排除當日 SupervisionFlag=True；實際 test 必須以 API 當天要求的股票清單為準。

模型輸入不含驗證 Target，各年排名先保存，再合併 Target 評分。Target 仍用於歷史訓練及驗證評分；正式 test 的 Target 由主辦方保留。

為覆蓋每日要求的所有股票，推論時缺失特徵逐項以 0 代入並記錄標記；這是沿用的補值規則，不表示缺失變動率真的等於零。1,864,363 筆排名中，7,514 筆有一日變動率缺失；381,200 筆入選持股中有 463 筆此類補值。含任何 T 或 return 補值的入選持股共 9,377 筆。全部 953 天的入選股票均有可用 Target。

未截尾的量變動率可能很大。例如 2019-02-05 股票 4592 的 VR1 約 1,053.49，表示成交量約為前日 1,054.49 倍。這類數值保留原值，可能對擬合與排名產生影響。

獨立核對已通過：233 萬筆原始資料的一日價量變動率、全部日期的唯一排名與雙側各 200 檔、全部 381,200 筆入選 g、官方權重及每日 spread；獨立重算 Sharpe=0.04674195239352688。v4 的全部排名和每日分數也成功重現。
