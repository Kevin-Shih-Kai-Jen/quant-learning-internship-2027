# v6：Expanding window、連續參數與每日 RMSE 更新

2026-09-12。依最後確認的規則，v6 保留 v5 的十一個價量特徵，改為每次資料窗擴大後，按時間順序重新走過全部已成熟歷史日期；每一天各自計算 400 檔的 RMSE，做一次 gradient descent 更新。**loss 不跨日期平均，參數只初始化一次，跨年不重設。**

相同 953 個歷史驗證日的 JPX 未年化 Sharpe：**v5=0.04674，v6=−0.06252**。新設定的結果較差；依要求保存為目前研究版本，v5 保留作比較。

## 每日 loss

對過去某一天 t 實際選出的多、空合計 400 檔 S_t，用目前正在更新的參數 θ 計算：

`L_t(θ) = sqrt( sum_i∈S_t (g_θ(x[t,i]) − Target[t,i])² / 400 )`

這是每日 **RMSE**，也就是每日 MSE 開根號。沒有把各日期的 loss 加總後平均，也沒有先跨日平均 MSE 再開根號。400 檔在 loss 中等權；JPX 的 2→1 排名權重只用於投組評分。

當 L_t>0，梯度為：

`∇L_t = sum_i∈S_t [(g_θ(x[t,i]) − Target[t,i]) × x[t,i]] / (400 × L_t)`

x 包含截距項；θ 沿負梯度方向更新。RMSE 為零時使用零次梯度。

## Expanding window 如何執行

1. 2017-01-04 起只將參數初始化為零一次，以 2017 年資料暖機。初始同分按照股票代碼決定次序，不使用 Target 打破同分。
2. 每個實際交易日收盤後，將 Target 已實現的 400 檔日批次加入歷史資料窗。Target 尚未實現的日期不能訓練。
3. 從最早到最新日期，走過全部累積批次一次。每個日期只用該日 400 檔 RMSE 做一次梯度步驟；後一批次從前一批次更新後的參數接續。
4. 用這次完整走訪後的參數，對當天股票排名、選取多空各 200 檔，並保存預測。等當天 Target 日後實現，再將這一批加入訓練窗。

例如已累積 A、B、C 三天：`既有 θ → 用 A 更新 → 用 B 更新 → 用 C 更新 → 預測新一天`。下一批 D 成熟後：`接續 θ → A → B → C → D → 預測`。各日樣本固定為當時實際選出的 400 檔；重訪時以目前 θ 重新計算預測誤差，不拿當時的舊誤差直接當梯度，也不以新參數重選歷史名單。

本次每次擴窗走一輪，並未宣稱每輪已收斂。步長使用 Armijo 回溯：初始基準 0.1，試探步長為上一接受步長的 1.5 倍，不滿足該日 loss 充分下降條件時減半，條件係數 0.0001。參數和步長狀態均接續。沒有最小平方法代替梯度下降、額外特徵標準化、梯度裁切或驗證分數調參。每一步降低該批次的 loss，不保證其他歷史日期的 loss 同時降低。

## 模型與資料

v5 原有 T5、T22、T60、V5、V22、V60、三個同期間價量 T 乘積，以及未標準化、未截尾的 PR1、VR1 全部保留，共十一特徵加截距。不加入 regime、Ridge、softmax 或交易成本。

訓練日期一直累積，最終包含 1,198 個完整日批次、479,200 筆歷史入選樣本，完成 1,197 次資料擴充後的完整走訪，共 **717,290 次每日批次梯度更新**。沒有數值停滯而未套用的步驟。2017-05-08 的 400 檔有一筆 Target 缺失，整天排除訓練，沒有補零標籤。若休市後同時有多個批次成熟，先全部加入，再走訪完整歷史窗一次。

完整走訪的計算使用每一天各自的 XᵀX、Xᵀy、yᵀy，以免重複載入該日 400 列；這和直接逐筆計算該日 RMSE 與梯度等價，**沒有把日期合併成一個平均 loss**。獨立核對以直接的 400 列殘差重算，結果一致。

每日股票池、缺失特徵填 0 與排名同分規則沿用 v5。推論不含 Target，當天實際入選股票名單在標籤可用前固定。股票池是提供的核心股票資料並排除當日 SupervisionFlag=True 的歷史近似，正式 test 仍須依 API 當日清單。

v6 四個年度分數皆低於 v5。本次同時改變年度訓練方式、訓練樣本來源（實際入選 400 檔）、loss 及參數更新流程；不能只將差異歸因於 expanding window 本身。

每日預測 RMSE 另逐日保存，使用當初預測時的 g 與後來實現的 Target；它和重訪訓練時使用目前 θ 的 RMSE 分開記錄。本報告不將每日 loss 跨日平均成一個訓練 loss。

## 核對與適用範圍

獨立核對通過：全程只有一次零初始化、所有日間參數連續、每次完整走過全部成熟歷史批次、標籤成熟時間與缺失批次排除、400 檔分組、全部 953 天的唯一排名及雙側 200 檔、每日 RMSE 與 JPX spread。

另以直接逐筆殘差重新執行首次、各年首次、最後一次完整梯度走訪，涵蓋最終 1,198 個日批次，與保存參數最大差異約 7.04×10⁻¹⁶。全部歷史入選預測由當天保存參數重算，最大誤差約 1.03×10⁻¹³。

這是歷史逐日驗證：已過去且已實現的驗證標籤可以進入後續訓練，當前預測不得使用未來標籤。資料先前已用於研究，並非新的保留測試集、正式 test 或排行榜成績。最後驗證訊號日為 2021-12-01；最後保存的更新參數截至 2021-12-03，其後實現的資訊沒有回填到 12 月 1 日的預測。
