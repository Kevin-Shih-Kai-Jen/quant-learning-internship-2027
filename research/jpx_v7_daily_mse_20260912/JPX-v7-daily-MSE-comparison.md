# v7：每天一次 gradient descent，等權 MSE 與官方排名權重參照

2026-09-12。依最新確認，主要模型使用當天全部股票的普通平均 MSE；第二種以 JPX 多空排名權重計算加權 MSE 作參照。兩版每個日期只做一次梯度更新，參數持續接續。這取代 v6 重訪歷史日期及使用 RMSE 的設定。

同樣 953 個歷史驗證日的 JPX 未年化 Sharpe：**等權版 0.00768；官方排名權重參照版 −0.04018**。等權版列為目前主模型，參照版另外保留。

## 每天實際做什麼

1. 用當時可用的參數對當天全部股票預測 g，排序並保存預測。參照版同時固定該日各股票的訓練權重。
2. 等該日 Target 實現，才計算這一天的 MSE 與梯度。
3. 套用一次 `θ_new = θ_old − η × gradient`，之後繼續使用這組參數。

每個日期的訓練資料只用一次；沒有重新走訪舊日期、同日多個 epoch 或跨年重新產生參數。MSE 不開根號，也不把不同日期的 loss 合併為本次更新的 loss。

訓練時 g_θ 使用「更新前目前的參數」對該日輸入重新計算。由於 Target 較晚實現，這個誤差與當初預測時的誤差可能不同；兩者分開記錄。參照版的排名權重仍固定為當初預測時的排名，沒有用後來的 Target 重選權重。

## 兩種 loss

### 主模型：v7_equal，全部股票等權

`L_t(θ) = (1 / N_t) × sum_i (g_θ(x[t,i]) − Target[t,i])²`

N_t 是當天股票池中具有可用 Target 的股票數。每個誤差平方都乘相同的 1/N_t。這裡的訓練股票數不是 400，只有 JPX 投組評分才選多空各 200 檔。

### 參照模型：v7_jpx，官方排名權重的 MSE

`L_t(θ) = sum_i a[t,i] × (g_θ(x[t,i]) − Target[t,i])² / sum_i a[t,i]`

每側由最極端排名起，第 1 名原始權重 2，第 200 名原始權重 1，中間線性遞減；做空側以預測值最低者作該側第 1 名。兩側都使用正的誤差權重。

- 多頭最高 200 檔：2→1。
- 空頭最低 200 檔：2→1。
- 其餘股票：0。

完整標籤下兩側原始權重總和為 600，所以單檔歸一化權重從 2/600 到 1/600。同樣大小的誤差平方，該側第 1 名的 loss 貢獻是第 200 名的兩倍。這實現了「較重要的持股承擔較大的預測誤差責任」。

這是將官方投組的排名權重用於自訂訓練 MSE，並非 JPX 官方規定的訓練 loss，也不是每檔對最終 Sharpe 的精確貢獻。Sharpe 還取決於每日組合收益的變動。這個參照設計同時把中間股票的訓練權重設為零，結果代表整個權重設定的效果。

## 梯度與學習率

將當日非負權重歸一化，使 sum_i w_i=1：

`gradient = 2 × sum_i w_i × (g_θ(x_i) − y_i) × x_i`

兩版皆依當天特徵與權重計算 `A = Xᵀ W X`，使用相同的步長規則：

`η = 1 / (2 × A 的最大特徵值)`

這是一個依當日特徵尺度決定的穩定純量學習率，避免未標準化成交量變動率導致過大的更新。兩版的具體步長可因訓練權重不同而不同；沒有搜尋驗證分數來選學習率。每一天仍只計算並套用一次梯度步驟，沒有用最小平方法求完一組新參數。

全部更新均使當日訓練 MSE 降低；這不保證之後的預測或 Sharpe 一定改善。

## 共同資料與時序

沿用 v5 的十一個特徵：六個價量水準 T 值、三個同期間價量 T 乘積，以及未標準化、未截尾的一日 PR1、VR1。沒有新增 regime、Ridge、softmax 或交易成本。

兩版都在 2017-01-04 初始化為相同的零參數，以 2017 年順序資料暖機，跨年度持續接續。股票池沿用提供的核心股票資料，排除當日 SupervisionFlag=True；缺失輸入依既有規則填 0 並記錄。預測不依 Target 是否缺失來篩股票。

每個 SignalDate 的 Target 只在對應 ExitDate 收盤可用後加入更新。標籤缺失時，僅排除該筆訓練誤差，對其餘有正權重的樣本重新歸一化，沒有將未知 Target 補零。等權版共排除 216 筆缺失 Target；參照版的正權重樣本有 1 筆缺失。

2020-10-01 全市場休市，不產生新排名；仍處理該日到期、資料中 Target 均為零的 2020-09-29 批次，因此不把兩個日期批次堆到隔天更新。每版共 **1,199 次更新**，每個日期最多一次、每個訊號日只訓練一次。等權版累計使用 2,325,806 筆有效誤差；參照版使用 479,599 筆正權重誤差。

最後驗證訊號日為 2021-12-01，最後已到期批次的參數更新截至 2021-12-03；後兩天的更新沒有回填進 12 月 1 日的預測。

## JPX 評分結果

兩版均每日以 g 排名，多空各 200 檔，評分採官方 2→1 權重。官方 Sharpe 使用每日 spread 平均除以樣本標準差（ddof=1），不乘 √252。[JPX 官方評分程式](https://www.kaggle.com/code/smeitoma/jpx-competition-metric-definition)。

所有 953 天的實際入選股票 Target 都完整，兩版與 v5 的比較使用完全相同日期及股票池。年度標籤沿用原驗證分組，某些年度首個訊號日在前一年的最後交易日。合併 Sharpe 從全部每日 spread 重算，沒有平均年度 Sharpe。

等權版的合併 Sharpe 較好，2018、2021 仍為負值；兩種新設定皆低於 v5。v5 的年度擬合方式與訓練流程不同，僅作歷史基準，不能用此比較單獨判定某一個因素的因果效果。依使用者要求，等權版作主模型，官方權重版本作參照，並未依分數更換主要訓練規則。

這是曾用於研究的歷史逐日驗證，已成熟的過去標籤可以訓練後續日期，未來標籤不可用於當前預測。並非新保留測試集、正式 test 或 Kaggle 排行榜成績。
