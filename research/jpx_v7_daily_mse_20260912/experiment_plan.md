# v7: one daily gradient-descent step, ordinary MSE; equal-weight main and JPX-weight reference

Latest confirmed user specification replaces v6: do not replay historical dates and do not take the square root of MSE. For each historical signal day's cross-section, update one continuous parameter vector exactly ONCE after its Target values become available. Initialize each variant to the same zero vector once at the start of 2017 data; no annual reset. Keep the same eleven v5 economic features, raw PR1/VR1, no scaling/clipping/Ridge/regime/softmax/costs. Preserve the historical core stock pool excluding contemporaneous SupervisionFlag and missing-input zero fallback used for prediction.

Main variant v7_equal: all stocks with observed labels get weight 1/N for that date's MSE. Do not restrict training to the 400 positions. Reference v7_jpx: each model's own predicted highest 200 and lowest 200 receive nonnegative official rank magnitudes, 2 linearly down to 1 from each extreme, zero elsewhere. Normalize weights across both sides (raw sum 600 for complete labels). Freeze rank-derived weights at prediction time before labels; do not recompute them at label release. Both long and short error weights are POSITIVE. This is a user-requested training surrogate using portfolio weights, not the official JPX training loss or each stock's exact contribution to Sharpe.

For each single daily batch, L(theta)=sum(w*(Xtheta-y)^2), grad=2 X'W(Xtheta-y). Take one actual negative-gradient parameter update. Use the same deterministic step-size rule for both variants: eta=1/(2*lambda_max(X'WX)), computed from that day's features and training weights only. This is a stable scalar learning rate for the quadratic loss, not feature standardization and not solving the regression to convergence. No line search, extra gradient steps, additional epochs, or score-based tuning. Save loss at the forecast parameters separately from loss immediately before/after the delayed training update.

Target timing: update only when historical ExitDate <= current close. Process daily calendar label releases, including 2020-10-01's scheduled label release, but do not generate a new forecast on that market closure date. The calendar mapping gives at most one cohort per label-release date, so at most one update per date per model. Persist each forecast/rank and (reference) training rank weights before evaluation. Missing Targets are excluded individually from that day's training loss, and the remaining positive weights are renormalized; do not infer unknown labels as zero and do not alter prediction universes from label availability. Log missing-label exclusions and effective sample counts.

Use 2017 for sequential warm-up, the same 953 v5 validation dates/fold labels, and official unannualized JPX Sharpe. Continue only outstanding cohort label releases through 2021-12-03 after the last forecast 2021-12-01. Compare versions on identical scorable dates; flag any selected missing Target. Save per-day losses, coefficient history, gradients/learning rates, training membership/weights, predictions and independent audits. Do not average daily training losses into the optimization objective. Existing v5/v6 remain preserved; v7_equal becomes the main active baseline after audit, v7_jpx is a reference regardless of which score is higher. Not a new holdout or formal test.
