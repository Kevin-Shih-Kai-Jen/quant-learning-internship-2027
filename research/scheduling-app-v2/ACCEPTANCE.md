# v0.2 驗收紀錄

日期：2026-09-25。這份紀錄只說明本機試用版，不等同上架驗收。

## 已驗證

- Node.js 26：17 個自動化測試全部通過。其中一項逐一比對 36 個小問題的完整解集合，使用不依賴正式規則驗證器的獨立窮舉程式。
- 跨午夜重疊、雙向班距、班數上限、連上限制、未確認資料、0 人需求、0 班上限、锁定衝突、12 層以上搜尋、死分支終止、搜尋預算與無解狀態。
- 草稿復原／重做後重載、發布版本不變、過期需求拒絕發布、新版明確重審、候選不能抹掉人工鎖定。
- JSON 完整備份驗證、拒絕無效發布版本及 prototype 欄位、CSV 跳脫與公式前綴保護、本機儲存失敗及多分頁覆蓋拒絕。
- 真實 Chromium 瀏覽器端到端：需求 → 凍結 → Worker 排班 → 預覽 → 套用 → 編輯／鎖定 → 發布兩個版本 → 查看舊版 → CSV 匯出。
- 從空白群組重新走完建立成員、建立一期、確認需求、產生並發布班表。
- 1512px 桌面與 390px 手機視窗；手機改用逐日卡片，頁面與需求對話框未產生水平溢出。
- 惡意 HTML 字串僅作文字顯示；整合流程未發生 JavaScript 或瀏覽器 console error。
- Service Worker 就緒後斷網重載，已發布本機班表仍可查看。
